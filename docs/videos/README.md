# Retrospective working product demonstrations

- [Sprint 1 outcome - 60 seconds](Sprint1_demo.webm): account login, categories, budget and dashboard totals.
- [Sprint 2 outcome - 120 seconds](Sprint2_demo.webm): transactions, edit, delete confirmation/cancel, filtered CSV, budgets, dashboard and 360px layout.

Both videos are actual browser recordings of the repaired working build with synthetic data. Captions identify them as retrospective current-build demonstrations recorded in November 2026. They are silent captioned videos; no student's voice or identity is imitated. They do not prove a video existed during the original October sprint dates.

Open WebM in Chrome, Edge, Firefox or VLC. The files are exactly 60.00 and 120.00 seconds at 25 fps. Screenshots and original run metadata are in ../reports/browser. The source recorder is scripts/browser_demo.cjs; launch scripts/demo_server.py on localhost using a disposable database before recording. Playwright and an isolated browser are tooling dependencies, separate from application requirements.
